# Style Guide — LogiFix B2B (Blok 6)

## 1. Farebná paleta

### Základné B2B farby
- **Tmavomodrá (Navy Dark — nadpisy, pätička):** `#0F172A`
- **Tmavomodrá (Navy Header — navigácia):** `#1E293B`
- **Primárna akcentová modrá (CTA tlačidlá, odkazy):** `#2563EB`
- **Hover modrá:** `#1D4ED8`
- **Pozadie stránky (Background Main):** `#F8FAFC`
- **Biela (Karty, tabuľky, modálne okná):** `#FFFFFF`
- **Hlavný text:** `#334155`
- **Tlmený text:** `#64748B`
- **Orámovanie (Border):** `#E2E8F0`

### Semaforový systém pre SLA stavy
- 🔴 **Kritické (Critical):** `#EF4444` (pozadie odznaku `#FEE2E2`, text `#991B1B`)
- 🟠 **Po SLA (Warning):** `#F97316`
- 🟡 **Čakajúce (Pending):** `#F59E0B` (pozadie odznaku `#FEF3C7`, text `#92400E`)
- 🟢 **Doručené / Vyriešené (Success):** `#10B981` (pozadie odznaku `#D1FAE5`, text `#065F46`)

---

## 2. Typografia

- **Rodina písma:** `'Inter', system-ui, -apple-system, sans-serif`
- **Hlavný nadpis (H1 Hero):** `2.5rem` (na mobile `1.8rem`), tučné (`700`)
- **Nadpisy sekcií (H2):** `1.8rem` – `2rem`, farba `#0F172A`
- **Bežný text:** `0.95rem` – `1.05rem`, riadkovanie `1.5`
- **KPI hodnoty:** `1.8rem`, extra tučné (`800`)

---

## 3. UI komponenty a rozloženie

- **Tlačidlá:** Zaoblenie `6px`, vnútorný odstup `0.6rem 1.2rem`, výrazný kontrast bieleho textu na modrom pozadí.
- **Karty a kontajnery:** Zaoblenie `8px` – `12px`, jemný tieň `0 4px 6px -1px rgba(0, 0, 0, 0.05)`.
- **Responzivita:** Breakpoint `768px` — hamburger menu na mobiloch, KPI mriežka zo 4 stĺpcov na 2 stĺpce, horizontálne posúvanie tabuľky.
